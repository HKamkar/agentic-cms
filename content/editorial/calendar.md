# Editorial calendar

One row per planned publication, in date order: `date` is the target week,
`slug` the future `content/blog/<slug>.md` (or `pages/<slug>.yaml` for a
page), `status` one of idea, brief, draft, review, published, retired,
`owner` who writes it. `pnpm content:status` prints the rows dated today
or later (a row is any table line whose first cell is a date). A published
row moves to the bottom table; the post file is the record. Briefs, SERP
reads and drafts may live in a workshop `workshop.yaml` names, outside this
repo.
