The life of one page

An agent writes. The build reads every word.

agentic-cms is a CMS with no database. Content is files, an AI agent edits them, and what ships is static.

0106

The open sea

A voice memo, half a post, a slide from last year. The words exist before the page does.

The brief

The words are already there They have no shore yet

Hand one of them to the agent as a brief. It comes back with an outline, and waits for your yes.

0206

The storm

A row in a database, a block in a builder, a string in a component. Every copy changes a little.

The drift

Copies multiply The truth gets harder to find

One price in the brochure, another on the site, a third in the code. An agent that only writes adds a fourth.

0306

The spine

One file for each page. Its SEO, its copy and its structured data, each in its place.

The file

A page is a file The agent edits it there

Every word a reader sees comes from content/ or the site's config. A change is a diff, and a person merges it.

0406

The gate

Nothing passes unread. What fails is held, and the reason is printed.

The build

The build says no and it says why

Every file is read against its schema and your voice rules, every built page against its SEO. A failure names the place and the problem, so the agent can fix it.

0506

The tree

What passed takes root. The light climbs, the branches follow, and every page finds its place.

The site

One root Every page in its season

Pages, posts, the feed and the sitemap all grow from content/. Retire a page, and the agent writes its redirect.

0606

First light

The page is built once. From here on it is a file.

The reader

The page is already there before the reader asks

Prerendered, and served from a Cloudflare Worker or a Node server. No database, no admin screen, nothing read at request time.

pnpm dlx agentic-cms init my-site --name "My Site"

Start a siteRead the code

Open source, MIT. Node 22.18 or later, and pnpm. It starts as a wireframe, and the design is yours.
