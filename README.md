# Demos

What GitHub Pages serves for agentic-cms. This branch holds built pages and
none of the kit's history.

- `motion-story/`: agentic-cms told as a motion story, the life of one page.
  Raw WebGL 2, no library, nothing asked of another server. The fonts are Figtree and
  JetBrains Mono, under the SIL Open Font License (`motion-story/fonts/`).
