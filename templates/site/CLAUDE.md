# Claude Code

The rules are `AGENTS.md`, shared with every agent; the path-scoped
invariants are `.claude/rules/`, each ending with a pointer to the kit's
whole rule in the package. The kit's skills are its `editorial` and `design`
plugins, from the package's marketplace (`.claude/settings.json`);
`.claude/skills/` holds the site's own.
